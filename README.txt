SISTEMA DE GESTIÓN DOCUMENTAL – RED DE SALUD

Proyecto desarrollado para la gestión y seguimiento de documentos de la Red Integrada de Salud N.º 04 Aguaytía – San Alejandro.

Tecnologías utilizadas:

* PHP
* HTML
* CSS
* JavaScript
* MariaDB/MySQL
* XAMPP

Módulos principales:

* Administración de usuarios
* Gestión de áreas
* Gestión de expedientes
* Derivación y seguimiento documental
* Historial de movimientos
* Notificaciones
* Gestión de documentos y anexos

El proyecto utiliza GitHub como repositorio para el almacenamiento y entrega del código fuente de la aplicación.
